## 怎么选：按使用场景对号入座

**只备份自己这一台电脑。** 先用标准版。官方给标准版列出的能力包括自定义备份计划、增量备份、压缩或分割备份任务，还有邮件通知，整块数据盘克隆到机械盘或固态盘也支持。换硬盘不想重装系统，这个免费功能就解决了。付费版多出来的东西，很多人一年用不上一次。

**需要异机还原，或者要把系统迁到新硬件。** 专业版。标准版的功能列表里没有异机还原，旧机器主板坏了、系统镜像要恢复到一台配置完全不同的新电脑上，就得往上买一档。这是专业版最值钱的地方，也是它和专业版以下唯一拉开差距的地方。

**装在公司的办公电脑上。** 工作站版。多 10 美元换商用授权，报销和合规上都好交代，被查到用个人版授权跑公司业务很难解释。

**机器多，或者要给别人装机收费。** 技术员版。按专业版 69.95 美元一台算，799 美元够买 11 台专业版授权，公司里机器少于 11 台，买技术员版其实更贵。它的真正价值是可以对外提供收费的技术服务，这一条专业版授权不允许。机器多但不对外的公司，算清楚再决定。

**服务器。** 服务器版。别拿专业版去装 Windows Server，授权范围和系统支持都不是一回事。

**这些人可以先不买。** Mac 用户直接排除，Backupper 只有 Windows 版本。只用网盘同步文件、不做系统镜像的人，网盘自带的功能就够了。一两年才搬一次数据的人，系统自带的复制粘贴和磁盘管理也能完成。👉 [对照你的场景看对应版本的价格](https://lizhi.shop/products/aomei-backupper?cid=7bbix2xj)

## 真实评价与几个容易踩的坑

独立评测不算多，能找到的最完整一份是 TechRadar 2020 年的测评。它认可的地方是功能覆盖面大，除了备份和还原，还能做文件实时同步和磁盘克隆，也能制作可启动介质。擦盘、检查镜像完整性、备份 iPhone 这些零碎功能也都有。对家庭用户和小型办公场景来说，这套功能已经够用。免费版给得多也是它相对同类产品的优势，很多对手把定时备份和增量备份都锁在付费版里。

缺点同样具体。第一，没有 macOS 版本，TechRadar 点名说这是它和 Acronis、EaseUS 的主要差距，Mac 用户不用往下看了。第二，客服只有邮件，没有在线聊天和电话，出问题只能等回信，急着重装系统的时候这一点很要命。第三，六个版本切得太细，专业版和工作站版只差 10 美元，很容易买错，买错之后能不能换、要不要补差价，得看经销商怎么处理。第四，标准版页面主要讲免费版能做什么，没有逐条列清哪些功能锁在付费版里，判断要不要升级得自己去翻对比页。

退款要单独说。傲梅官方页面标的是 90 天无条件退款，那是厂商直营的条款。从经销商手里买的授权，退款走经销商的规则，下单前问一句，别默认自己也有 90 天。
